# Лабораторная работа №3: Введение в специальность

## Задание
Разработка консольного приложения на C# с интерактивным меню. Программа включает в себя математическую игру «Отгадай ответ», вывод информации об авторе и демонстрацию алгоритмов сортировки массива (пузырьком и выбором).

## Как запустить
Для запуска проекта вам понадобится установленный .NET SDK. 
1. Откройте терминал в папке с проектом.
2. Выполните команду:
   `dotnet run`
   
*(Либо откройте файл решения `.sln` в Visual Studio и нажмите F5)*

## Пример работы

### 1. Игра «Отгадай ответ»
Пользователю предлагается угадать значение математической функции. Дается 3 попытки, ответ нужно округлить до 2 знаков после запятой.

**Ввод:**
```text
1
30
0.5
1.2
```

**Вывод:**
```text
1. Отгадай ответ
2. Об авторе
3. Сортировка массива
4. Выход
Вы должны угадать ответ f((sin(a) + tg(2a)) / sqrt(log3 e^2))
на это вам дается 3 попытки, ответ должен быть округлен до 2 знаков после запятой
Введите число а: 
(sin(a) + tg(2a)) / sqrt(log3 e^2) = ?
Неверно, попробуйте еще раз, оставшихся попыток 2
Неверно, попробуйте еще раз, оставшихся попыток 1
Неверно, попробуйте еще раз, оставшихся попыток 0
Вы проиграли, правильный ответ - 0.57
```

### 2. Сортировка массива
Программа генерирует случайный массив, выводит его, а затем сортирует двумя способами (пузырьком и выбором), замеряя время выполнения.

**Ввод:**
```text
3
5
```

**Вывод:**
```text
Введите размер массива: 
Bubble:
-12 5 8 -3 20
Сортировка пузырьком - Время выполнения: 00:00:00.000123
-12 -3 5 8 20

Select: 
-12 5 8 -3 20
Сортировка выбором - Время выполнения: 00:00:00.000089
-12 -3 5 8 20
```

### 3. Выход из программы
Для завершения работы программы выберите пункт `4` и подтвердите выход.

**Ввод:**
```text
4
д
```

**Вывод:**
```text
д - выйти из программы, при нажатии н – остаться в программе
Выход из программы
END PROGRAM
```
