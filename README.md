## Лабораторная работа №3 
## Задание
Создать консольное приложение на языке C# на основе кода лабораторной
работы № 2, которое выполняет следующие действия: угадайка, об авторе, работа с одномерными массивами, выход из приложения

## Как запустить
Для запуска проекта вам понадобится установленный .NET SDK. 
1. Откройте терминал в папке с проектом.
2. Выполните команду:
   `dotnet run`
